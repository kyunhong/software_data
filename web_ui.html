UI · UX와 사용성 원칙

지금 볼 탭 · 학습지

UI(사용자 인터페이스)는 사용자가 보고 누르는 화면 요소이고, UX(사용자 경험)는 그 화면을 쓰면서 느끼는 편리함·만족감이에요. 좋은 UI는 아래 원칙을 지켜 좋은 UX를 만들어요.

사용성 원칙뜻오늘 웹 스튜디오에서
일관성같은 기능은 모든 페이지에서 같은 모양·같은 자리에 둬요.공통 메뉴, 사이트 전체 포인트 색·글꼴
피드백사용자가 무언가를 하면 결과를 바로 보여 줘요.누른 탭 색 바뀜, 퀴즈 정답 메시지, 체크리스트 달성률
접근성누구나(시각 장애, 작은 화면 등) 쓸 수 있게 만들어요.이미지 alt, 글자와 배경의 명도 대비, 충분한 글자·버튼 크기
반응형 · 모바일 우선화면 크기에 맞춰 배치가 바뀌고, 폰에서 먼저 편해야 해요.2열 배치가 폰에서 세로로 쌓임, 폰 화면 점검
정보를 정리하는 상호작용내용이 많으면 한 화면에 다 늘어놓지 말고 탭(나눠 보기), 접기(필요할 때 펼치기), 팝업(자세한 내용만 따로), 슬라이드(사진 넘겨 보기)로 정리해요. 모두 클릭 이벤트가 일어나면 JS가 화면을 바꾸는 방식이에요.
확인 지점UI와 UX의 차이, 그리고 사용성 원칙 4가지를 각각 한 문장으로 설명할 수 있으면 통과.
1

웹 스튜디오 열기 ↗
확인 지점메뉴로 페이지를 옮겨 다녀도 색과 글꼴이 똑같으면 통과.
2

상호작용 2개 이상 넣기

지금 볼 탭 · 웹 스튜디오

블록 넣기의 상호작용 묶음에서 내 페이지 내용에 맞는 것을 2개 이상 골라 넣어요. 예: 자기소개를 탭(성격·취미·꿈)으로 나누기, 궁금한 점을 접기(FAQ)로 정리하기, 사진을 슬라이드로 묶기.

확인 지점상호작용 블록 2개 이상이 내 내용으로 바뀌어 있고, 동작 보기에서 눌렀을 때 모두 동작하면 통과.
3

내 관심 분야에 맞는 기능 1개 이상 넣기

지금 볼 탭 · 웹 스튜디오

블록 넣기의 기능 묶음은 방문자에게 쓸모 있는 작은 도구예요. 수행평가에서 만들 웹을 떠올리며 내 관심 분야와 연결되는 것을 골라요.

기능이렇게 써 볼 수 있어요
퀴즈나에 대한 퀴즈, 진로 분야 상식 퀴즈 (예: 응급처치 순서, 영어 단어)
체크리스트운동 루틴, 시험 준비, 분리배출 확인
D-day · 타이머수행평가·시험 D-day, 공부 집중 타이머, 운동 인터벌
유튜브 · 지도좋아하는 강연·노래, 우리 동네 추천 장소 (집 주소는 넣지 않아요)
2열 · 3열 배치나란히 비교하기. 폰에서는 자동으로 세로로 쌓여요(반응형).
체크리스트 기록은 어디에 저장될까?체크한 결과는 방문자 각자의 브라우저에만 저장돼요. 그래서 다른 사람이나 다른 기기와는 공유되지 않아요. 여러 사람의 기록을 모으려면 서버와 데이터베이스가 필요해요. 다음 시간에 할 내용이에요.
확인 지점기능 블록이 내 관심 분야와 연결된 내용으로 바뀌어 있고, 동작 보기에서 동작하면 통과.

안 될 때

웹 스튜디오가 비어 있어요 (다른 컴퓨터예요)

지난 시간에 내려받은 파일이 있으면 내려받아 둔 파일 불러오기로 모두 골라요. 없으면 GitHub에서 index.html 코드를 내 코드 붙여넣기로 불러오고, 나머지 페이지는 ＋ 새 페이지 → 코드 붙여넣기로 하나씩 가져와요(파일 이름을 저장소와 똑같이). 가져온 뒤에는 올리기 탭에서 바뀌지 않은 파일에 올렸어요를 눌러 둬요.

편집 화면에서 탭을 눌러도 내용이 안 바뀌어요

편집 화면에서는 고치기 쉽게 탭 내용이 모두 펼쳐져 있어요. 실제 동작은 ▶ 동작 보기에서 확인해요.

팝업 버튼을 눌러도 창이 안 떠요
  • ▶ 동작 보기에서 눌렀는지 확인해요.
  • 팝업 블록을 복제하지 않고 버튼만 따로 복사했다면 연결이 끊겨요. 팝업 블록을 새로 넣어요.
유튜브가 "동영상을 재생할 수 없음"이라고 나와요

영상 주인이 다른 사이트에서 재생하지 못하게 막아 둔 영상이에요. 다른 영상을 골라요.

글꼴을 바꿨는데 일부 글자는 그대로예요

아이콘이나 그림으로 된 글자는 바뀌지 않아요. 내 사이트에서는 Ctrl+F5로 새로 고쳐 봐요. 글꼴 파일을 인터넷에서 받아 오므로 처음 열 때 잠깐 원래 글꼴로 보일 수 있어요.

폰 점검에서 가로 넘침이 계속 나와요
  • 문제를 눌러 선택된 요소에서 꾸밈 → 너비 → 꽉 차게를 골라요.
  • 그래도 남으면 바깥 요소 고르기를 눌러 더 큰 상자에도 같은 방법을 써요.
  • 긴 영어 단어나 주소가 한 줄로 이어져 넘칠 수 있어요. 글자를 줄이거나 띄어 써요.
다크 모드에서 사진 색이 이상해요 / 원래 색으로 돌아가고 싶어요

다크 모드는 페이지 색을 반전시키는 방식이라 일부 색이 예상과 다를 수 있어요. 버튼을 한 번 더 누르면 원래대로 돌아와요.

체크리스트를 체크했는데 다른 기기에서는 비어 있어요

정상이에요. 체크 기록은 그 브라우저에만 저장돼요. 여러 기기·여러 사람이 기록을 함께 보려면 데이터베이스가 필요해요(7차시).

오늘의 용어

UI사용자 인터페이스. 사용자가 보고 누르는 화면 요소(버튼, 메뉴, 입력 칸 등)
UX사용자 경험. 서비스를 쓰면서 느끼는 편리함과 만족감
사용성사용자가 원하는 일을 쉽고 빠르게 해낼 수 있는 정도
이벤트 · 이벤트 처리기클릭·입력처럼 웹 페이지에서 일어나는 일이 이벤트, 그때 실행되도록 등록한 JS 함수가 이벤트 처리기(addEventListener)
반응형 웹화면 크기에 맞춰 배치가 자동으로 바뀌는 웹. CSS의 미디어 쿼리(@media)로 만들어요.
웹 접근성장애가 있거나 환경이 달라도 누구나 웹을 이용할 수 있게 하는 것. 예: 이미지 alt, 명도 대비
명도 대비글자와 배경의 밝기 차이. 차이가 클수록 읽기 쉬워요.

6차시 정리

오늘 한 것: 사용성 원칙(일관성·피드백·접근성·반응형)에 맞춰 화면을 다듬고, 클릭 이벤트로 화면이 바뀌는 상호작용을 넣었어요. 다음 시간에는 방문자가 입력한 내용을 데이터베이스에 저장하고 다시 보여 주는 기능을 만들어요.
