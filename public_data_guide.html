공개 데이터 수집하기

데이터 수집 방법 중에서도 학생이 가장 쉽고 안전하게 실습할 수 있는 건 공개 데이터 활용이야 — 정부·공공기관이 이미 정리해서 내놓은 데이터를 가져다 쓰는 방법이지. 이 페이지는 그 과정을 실제 사례로, 아주 구체적으로 보여줄게. 사이트에서 검색하는 법부터 내려받은 파일을 점검하는 법까지.

4단계 실전 과정 2가지 실제 사례 30+개 데이터 사이트
실전 과정

공개 데이터, 이렇게 가져와

공개 데이터 활용은 아래 네 단계만 기억하면 돼. 하나씩 뜯어보자.

1

사이트 고르기

내 관심 분야에 맞는 사이트를 하나 정해. 아래 "나만의 데이터 탐험 지도"에서 카테고리별로 찾아볼 수 있어 — 공공데이터포털처럼 모든 분야를 다 검색해볼 수 있는 곳부터 시작하는 게 제일 편해.

2

키워드로 검색하기

사이트 안에서 원하는 키워드로 검색해봐. 결과가 너무 많이 나오면 기간·지역·제공 기관 같은 필터를 걸어서 범위를 좁혀나가.

💡 검색어를 너무 구체적으로 넣으면 오히려 안 나올 수 있어 — 넓은 단어로 먼저 검색해봐
3

형식 확인하고 내려받기

같은 데이터도 CSV, 엑셀(xlsx), API 등 여러 형식으로 제공될 수 있어. 오렌지(Orange3)에 바로 넣으려면 CSV나 엑셀 형식을 고르는 게 가장 편해. "미리보기" 기능이 있으면 내려받기 전에 먼저 확인해봐.

💡 API는 프로그램이 실시간으로 요청해서 받는 방식이라 코딩이 필요해 — 지금 단계에선 CSV·엑셀부터
4

파일 열어서 점검하기

내려받은 파일을 실제로 열어서 "이 데이터를 믿고 써도 될까?"를 확인해. 열(컬럼) 제목이 무엇을 뜻하는지, 단위는 무엇인지, 빈칸(결측치)이 있는지부터 살펴봐.

실제 사례

실제로 이렇게 해봤어

말로만 들으면 감이 안 오니까, 이 수업에서 실제로 내려받아 써본 공개 데이터 두 가지를 그대로 보여줄게.

CASE 1 · 날씨 · 환경

🌡️ 기상자료개방포털 — 기온 데이터

검색서울(108번 지점)의 연도별 기온 자료
형식CSV, cp949(한글 윈도우) 인코딩으로 제공됨
범위1907년 ~ 2025년, 100년이 넘는 기록
실제로 열어보면 평균기온·평균최저기온·평균최고기온 등의 열이 있고, 결측치는 1907·1950·1953년(근대 관측 초기, 6·25전쟁 전후 시기)에만 있었어 — 나머지 대부분의 해는 깨끗했어. 평균최고기온이 가장 높았던 해는 2018년(39.6°C), 가장 낮았던 해는 1953년(16.2°C)이었어.
CASE 2 · 교육

🏫 국가통계포털(KOSIS) — 사교육비 데이터

검색학년 및 시도별 학생 1인당 월평균 사교육비(고등학교)
형식엑셀(xlsx) 다운로드
범위2019년 ~ 2025년, 전국 17개 시도, 단위 만원
교육부·국가데이터처가 함께 만드는 「초중고사교육비조사」(표 ID DT_1PE105_3) 원자료야. 표 형태로 깔끔하게 정리돼 있어서 오렌지에 바로 넣기 좋았고, 이 자료로 결측치 채우기·이상치 찾기·정규화까지 실습하는 웹앱도 실제로 만들었어.
파일 점검법

내려받은 파일, 이렇게 생겼어야 해

같은 데이터라도 파일이 정리된 방식에 따라 오렌지에 바로 넣을 수도, 못 넣을 수도 있어. 아래는 이해를 돕기 위한 예시야(실제 통계는 아님).

📖 공공 데이터는 무조건 다 좋은 걸까? — 정부나 기관이 데이터를 공개한다고 해서 그 데이터가 항상 완벽한 건 아니야. 개인정보가 섞여 있거나, 오래돼서 최신 상황과 다르거나, 품질 관리가 안 된 자료일 수도 있어. 그래서 데이터 전문가들은 "이 출처가 믿을 만한가?", "최근에 갱신된 자료인가?"를 항상 먼저 점검해.
