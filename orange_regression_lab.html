회귀분석 해보기

오렌지 연습하기에서 다룬 포켓몬 데이터를 1세대(전국도감 1~151번) 전체로 넓혀서, 이번엔 한 걸음 더 들어가 볼 차례야. 무게로 체력(HP)을 예측하는 식을 오렌지가 실제로 어떻게 만들어내는지, File → Scatter Plot → Linear Regression → Test and Score → Predictions 5단계로 직접 따라가 봐. 전부 실제 Orange3를 실행해서 캡처한 화면이야.

회귀분석이 뭐야?

Scatter Plot으로 "두 변수가 관계가 있는지"는 이미 확인해봤어(상관계수 r). 회귀분석은 거기서 한 걸음 더 나가서, 그 관계를 "이 값을 넣으면 저 값이 나온다"는 구체적인 식으로 만드는 거야. 식이 있으면 데이터에 없던 새로운 경우도 예측할 수 있어.

  1. 목표(Target) 정하기 — 무엇을 예측하고 싶은지 정해. 여기서는 체력(HP).
  2. 식 학습시키기 — Linear Regression 위젯이 데이터에 가장 잘 맞는 직선(식)을 찾아줘.
  3. 성능 확인하기 — 그 식이 얼마나 잘 맞는 식인지 Test and Score로 점수를 매겨.
  4. 새 데이터에 적용하기 — Predictions 위젯으로 처음 보는 데이터에도 식을 적용해봐.

이번 실습 관계

무게(Weight)로 체력(HP)을 예측해볼 거야. 1세대 포켓몬 151마리 전체 데이터에서 두 값의 상관계수는 r = 0.45 — 무게가 많이 나갈수록 체력도 어느 정도 높아지는 경향은 있지만, 종류가 다양해질수록 예외도 많이 섞여 있어 관계가 더 느슨해졌어. (체력을 가장 잘 설명하는 재료가 뭔지 다시 확인하려고 151마리 데이터의 공격·방어·스피드·무게 조합 상관계수를 모두 계산해봤는데, 그중에서도 무게가 체력과 가장 상관이 높았어.)

전체 파이프라인 한눈에 보기

지금까지 연습한 5단계를 모두 연결하면, 실제 오렌지 캔버스는 이런 모습이 돼. File(훈련 데이터, 151마리) 하나에서 Scatter Plot·Linear Regression으로 뻗어나가고, Linear Regression은 다시 Test and Score·Predictions 두 갈래로 이어져. Predictions에는 File(새 포켓몬 — 가상의 메가홍균X)에서 온 데이터도 함께 들어가. (아래는 실제로 Orange3를 실행해서 캡처한 캔버스 화면이야.)
