웹페이지는 무엇으로 만들까

웹페이지에서 사용자가 보고 누르는 화면을 프론트엔드라고 해요. 프론트엔드는 세 가지 언어로 만들어요.

HTML구조제목, 글, 버튼, 그림 같은 요소를 화면 어디에 둘지 정해요.
CSS디자인색, 글자 크기, 배치 같은 모양을 정해요.
JavaScript동작버튼을 누르면 무슨 일이 일어날지 정해요.
왜 "파일 하나에 다 넣어 줘"라고 할까?세 가지를 파일 하나(index.html)에 모아 두면, 다음 시간에 인터넷에 올릴 때 그 파일 하나만 올리면 돼요.

안 될 때

GitHub에 올렸더니 흰 화면만 나와요

코드 첫 줄이 <!DOCTYPE html>이 아니고 import React 같은 글자로 시작하면 웹페이지가 아니라 React 코드예요. Gemini에게 "React 없이 HTML 파일 하나로 다시 만들어 줘"라고 요청하세요.

Canvas 메뉴가 안 보여요

학교 구글 계정은 Gemini나 Canvas가 막혀 있을 수 있어요. 손을 들어 선생님께 알려 주세요.

미리보기가 하얗게 비어 있어요

조금 더 기다려 보세요. 그래도 비어 있으면 "미리보기가 안 나와. 다시 만들어 줘"라고 부탁해요.

Canvas가 안 열리고 글로만 답해요

1단계에서 Canvas가 켜져 있는지 확인하고, "Canvas로 만들어 줘"라고 다시 부탁해요.

고쳤더니 다른 부분이 망가졌어요

Canvas 위쪽 ↶ 되돌리기를 누르거나 "방금 바꾼 거 되돌려 줘"라고 말해요. 그리고 하나씩만 부탁해요.

코드를 고쳤더니 화면이 이상해요

꺾쇠 < >나 따옴표를 지웠을 수 있어요. Ctrl+Z로 되돌리세요.
