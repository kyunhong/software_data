데이터베이스 설계하기

지금 볼 탭 · 학습지

다음 시간에 자기소개 페이지에 OX 투표와 방명록을 붙여요. 두 기능은 저장할 내용이 달라서, 데이터베이스 안에 표(테이블)를 두 개 만들어요. 구글 시트에서는 아래쪽 탭 하나가 표 하나예요.

방명록 탭
ABCD
1시간닉네임내용
2
OX 탭
ABCD
1시간답
2

1번째 줄 = 필드 이름. 2번째 줄부터 데이터가 한 줄(레코드)씩 쌓여요. 시간 필드는 저장할 때 백엔드가 자동으로 채워요. OX 탭의 답에는 O 또는 X가 들어가요.

백엔드 코드 넣기 (앱스 스크립트)

지금 볼 탭 · 구글 시트 → 앱스 스크립트

아래 코드는 GET 요청이 오면 두 표(방명록·OX)의 데이터를 응답하고, POST 요청이 오면 받은 데이터를 알맞은 표에 새 행으로 저장해요. 함수 이름 옆 주석을 읽으며 붙여넣어 보세요.

// 권한을 이 스프레드시트 하나로만 좁히기 /** @OnlyCurrentDoc */ // 이름으로 표(시트 탭) 찾기 function table(name) { return SpreadsheetApp.getActiveSpreadsheet().getSheets() .find(s => s.getName().trim().toUpperCase() === name.toUpperCase()); } // 표의 1행(필드 이름) 읽기 function fields(sheet) { if (!sheet || sheet.getLastColumn() === 0) return null; return sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0].map(h => String(h).trim()); } // 표의 모든 레코드를 [{필드: 값}, ...] 목록으로 만들기 function records(sheet) { const head = fields(sheet); if (!head || sheet.getLastRow() < 2) return []; const rows = sheet.getRange(2, 1, sheet.getLastRow() - 1, head.length).getValues(); return rows.map(r => { const item = {}; head.forEach((h, i) => item[h] = r[i]); return item; }); } // GET 요청이 오면: 레코드를 JSON으로 응답 function doGet(e) { const p = (e && e.parameter) || {}; if (p.head) return out({ 방명록: fields(table('방명록')), OX: fields(table('OX')) }); // 필드 이름 확인용 const key = p.count ? 'count' : 'get:' + (p.sheet || 'all'); const cache = CacheService.getScriptCache(); const saved = cache.get(key); if (saved) return out(JSON.parse(saved)); // 2초 안에 같은 요청이 또 오면 저장해 둔 결과로 바로 응답 let result; if (p.count) { // OX 개수 세기(집계) result = { O: 0, X: 0 }; records(table('OX')).forEach(r => { const a = String(r['답']).trim().toUpperCase(); if (a in result) result[a]++; }); } else if (p.sheet) result = records(table(p.sheet)).slice(-50); // 표 하나, 최근 50개 else result = { 방명록: records(table('방명록')), OX: records(table('OX')) }; // 전체 cache.put(key, JSON.stringify(result), 2); return out(result); } // POST 요청이 오면: 받은 데이터를 해당 표의 맨 아래 새 레코드(행)로 추가 function doPost(e) { const data = JSON.parse(e.postData.contents); const name = data.sheet === 'OX' ? 'OX' : '방명록'; const lock = LockService.getScriptLock(); lock.waitLock(20000); // 여러 명이 동시에 저장해도 한 명씩 차례로 저장 try { const sheet = table(name) || SpreadsheetApp.getActiveSpreadsheet().insertSheet(name); if (!fields(sheet)) sheet.appendRow(name === 'OX' ? ['시간', '답'] : ['시간', '닉네임', '내용']); const row = fields(sheet).map(h => h === '시간' ? new Date() : String(data[h] || '').slice(0, 100).replace(/^[=+\-@]/, "'$&")); // 100자까지, 수식은 글자로 저장 sheet.appendRow(row); } finally { lock.releaseLock(); } CacheService.getScriptCache().removeAll(['get:all', 'get:' + name, 'count']); // 저장해 둔 결과 지우기 return out({ ok: true }); } // 응답을 JSON 형식으로 만드는 함수 function out(obj) { return ContentService.createTextOutput(JSON.stringify(obj)) .setMimeType(ContentService.MimeType.JSON); }
위쪽의 ▷ 실행 버튼은 누르지 마세요.이 코드는 요청이 와야 실행돼요. 실행을 누르면 빨간 오류가 나는데, 정상이에요.
확인 지점편집 화면 위쪽에 Drive에 저장됨이 보이면 통과.

백엔드를 웹 앱으로 배포하기

지금 볼 탭 · 앱스 스크립트

배포하면 백엔드를 부를 수 있는 API 주소가 생겨요. 다음 시간에 프론트엔드가 이 주소로 요청을 보내요.

처음 한 번은 권한 부여 창이 나와요. 내 백엔드가 내 시트를 읽고 쓸 수 있게 허락하는 과정이에요.

이 경고는 "내가 만든 코드"일 때만 넘어가요.구글이 검사하지 않은 앱이라서 나오는 경고예요. 다른 사람이 보낸 링크나 모르는 사이트에서 이 경고가 뜨면 절대 넘어가지 말고 창을 닫아요.
5

API 주소 시험하기

지금 볼 탭 · 새 탭

주소창에 API 주소를 넣고 열면 백엔드에 GET 요청을 보내는 것과 같아요. 백엔드가 두 표의 내용을 JSON으로 응답해요.

{"방명록":[],"OX":[]}은 무슨 뜻?JSON에서 { }는 이름표가 붙은 묶음, []는 "빈 목록"이에요. 방명록 표와 OX 표에 아직 저장된 레코드가 없어서 둘 다 비어 있어요. 다음 시간에 데이터를 저장하면 여기에 내용이 생겨요.
확인 지점화면에 {"방명록":[],"OX":[]}가 보이면 통과. 로그인 화면이나 오류가 나오면 아래 안 될 때를 보고, 그래도 안 되면 손 들기.

안 될 때

API 주소를 열면 로그인하라고 나와요

4단계 액세스 권한이 있는 사용자가 모든 사용자가 아니에요. 배포 → 배포 관리 → 연필 ✏에서 모든 사용자로 바꾸고 배포를 눌러요. 학교 구글 계정은 이 선택지가 없을 수 있어서 개인 계정으로 해야 해요.

주소를 열었더니 오류 글자가 나와요
  • 3단계 코드를 빠짐없이 붙여넣고 저장했는지 보세요.
  • 주소 끝이 /exec인지 보세요.
  • 코드를 고쳤다면 다시 배포해야 해요: 배포 → 배포 관리 → 연필 ✏ → 버전: 새 버전 → 배포. 주소는 그대로예요.
실행 버튼을 눌렀더니 빨간 오류가 났어요

괜찮아요. 이 코드는 요청이 와야 실행돼요. 그냥 4단계로 가세요.

A1에 필드 이름이 한 칸에 몰려 들어갔어요

Ctrl+Z로 되돌린 뒤 A1을 다시 누르고 붙여넣어요. 그래도 안 되면 한 칸에 하나씩 직접 써요. 띄어쓰기까지 학습지와 똑같이 써야 해요.

방명록·OX 탭 이름을 잘못 썼어요

탭을 더블클릭해서 방명록, OX로 고쳐요. 띄어쓰기 없이, OX는 영어 대문자예요. 고친 뒤 코드나 배포는 다시 할 필요 없어요.

팝업 창이 안 떠요

주소창 오른쪽 끝의 팝업 차단 아이콘을 눌러 항상 허용을 고르고 다시 액세스 승인을 눌러요.
