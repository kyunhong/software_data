내 웹페이지 배포하기

1차시에 만든 웹페이지를 GitHub에 올려서, 누구나 접속할 수 있는 나만의 주소를 만들어요. 한 줄에 한 가지씩, 끝낸 줄은 체크하세요. 버튼 이름은 화면에 보이는 영어 그대로 적었어요.

② 저장소내 폴더 만들기

?

배포와 호스팅

지금 내 웹페이지는 Gemini 안에만 있어서 나만 볼 수 있어요. 다른 사람도 주소로 접속하려면 인터넷에 항상 켜져 있는 컴퓨터(서버)에 파일을 올려야 해요.

배포Deploy만든 프로그램을 누구나 쓸 수 있게 공개하는 것
호스팅Hosting내 파일을 서버에 올려 두고 주소로 접속하게 해 주는 서비스. 오늘은 GitHub Pages를 써요.
URL주소아이디.github.io/저장소이름/ 모양으로 만들어져요.
1

GitHub 가입하기

지금 볼 탭 · 오른쪽 크롬 창
확인 지점오른쪽 위에 내 프로필 동그라미가 보이면 가입 완료.
2

내 이메일 숨기기

지금 볼 탭 · GitHub

GitHub에 파일을 올리면 올린 사람의 이메일이 기록에 남을 수 있어요. 이메일에 이름이 들어 있을 수 있으니 먼저 숨겨 둬요.

확인 지점스위치 옆 글자가 On이면 통과.
3

1차시 코드 복사하기

지금 볼 탭 · Gemini (새 탭)
1차시에 웹 도구(추가 활동)로 만들었다면구글 드라이브에서 내 웹페이지 코드 문서를 열고 Ctrl+A → Ctrl+C 하세요. 웹 도구는 닫고 1시간이 지나면 저장된 내용이 지워져요. 그래서 꼭 구글 드라이브 문서에서 복사해요.
1차시 대화가 안 보이면1차시에 구글 드라이브에 올린 HTML 파일을 내려받아 마우스 오른쪽 → 연결 프로그램 → 메모장으로 열고 Ctrl+A → Ctrl+C 해도 돼요.
4

저장소 만들기

지금 볼 탭 · GitHub

저장소(Repository)는 인터넷에 있는 내 프로젝트 폴더예요.

확인 지점Quick setup이라는 파란 상자가 있는 화면이 나오면 통과.
5

코드 올리고 커밋하기

지금 볼 탭 · GitHub
커밋(Commit)이란?파일을 저장하면서 "언제, 무엇을 바꿨는지" 기록을 남기는 것이에요. 커밋 메시지가 그 기록의 제목이에요.
확인 지점저장소 화면에 index.html과 내가 쓴 커밋 메시지가 보이면 통과.
6

GitHub Pages로 배포하기

지금 볼 탭 · GitHub
확인 지점Save 후 1~2분 기다려요. 바로 누르면 404 화면이 떠요. 새 탭에 1차시에 만든 내 웹페이지가 열리면 통과.
7

내 폰으로 열어 보기

지금 볼 탭 · 학습지

아이디를 넣으면 내 웹사이트 주소와 QR 코드가 만들어져요. 폰 카메라로 찍으면 바로 열려요.

https://blue-cat-2026.github.io/my-page/
확인 지점폰 화면에서 내 웹페이지가 열리면 통과. 화면이 잘리거나 글자가 너무 작으면 8단계에서 고쳐요.
8

고쳐서 다시 배포하기

지금 볼 탭 · Gemini → GitHub
확인 지점폰에서 바뀐 화면이 보이고, Commits에 기록이 2개 이상이면 통과.

안 될 때

GitHub에 올렸더니 흰 화면만 나와요

코드 첫 줄이 <!DOCTYPE html>이 아니고 import React 같은 글자로 시작하면 웹페이지가 아니라 React 코드예요. Gemini에게 "React 없이 HTML 파일 하나로 다시 만들어 줘"라고 요청하세요.

404 화면이 떠요
  • 조금 더 기다려 보세요. 10분까지 걸릴 수 있어요.
  • 파일 이름이 정확히 index.html인지 보세요.
  • 6단계에서 Save를 눌렀는지 보세요.
  • 주소의 아이디와 저장소 이름에 오타가 없는지 보세요.
웹페이지 대신 코드 글자가 그대로 보여요

파일 이름 끝이 .html이 아니에요. index.html을 누르고 연필 ✏ → 맨 위 이름을 index.html로 고친 뒤 커밋하세요.

고쳤는데 예전 화면이 나와요

1~2분 기다린 뒤 PC는 Ctrl+F5, 폰은 새로고침을 눌러 보세요.

my-page 이름을 쓸 수 없대요

이미 같은 이름의 저장소가 있는 거예요. my-page2처럼 바꾸고, 7단계 주소의 my-page 부분도 같이 바꿔서 생각하세요.

로그인할 때 이메일로 코드를 보냈대요

새 컴퓨터에서 로그인하면 확인 코드를 보내요. 같은 구글 계정의 Gmail을 열어 GitHub가 보낸 숫자를 입력하세요.

2단계 인증(2FA)을 하라고 나와요

혼자 하지 말고 손을 들어 선생님을 불러 주세요.

화면이 사진이랑 조금 달라요

GitHub 화면은 가끔 바뀌어요. 같은 이름의 버튼을 찾으면 돼요. 못 찾으면 손을 들어 주세요.
